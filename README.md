# Internship Workspaces

A shared workspace for Piksel internship programs. It supports assignments, working notes, progress records, and collaboration across each program.

## Structure

```text
programmes/
  <program-name>/
    README.md
    interns/
      <github-username>/
        daily-logs/
        weekly-recaps/

templates/
  daily-log.md
  weekly-recap.md
```

Each program has its own directory under `programmes/`. Its README defines the program’s scope, participants, and any program-specific guidance.

Templates provide a shared starting point for daily logs and weekly recaps.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the shared working conventions.
