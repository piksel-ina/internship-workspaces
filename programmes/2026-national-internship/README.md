# 2026 National Internship

## Workspace

Each intern works in a directory named after their GitHub username:

```text
interns/<github-username>/
```

Keep work related to the internship inside this program directory.

## Daily logs

Create daily logs in:

```text
interns/<github-username>/daily-logs/YYYY-MM-DD.md
```

Start from [`templates/daily-log.md`](../../templates/daily-log.md).

Submit each daily log through a pull request.

## Weekly recaps

Create a weekly recap in:

```text
interns/<github-username>/weekly-recaps/YYYY-MM-DD.md
```

Start from [`templates/weekly-recap.md`](../../templates/weekly-recap.md).

Submit the recap with the final daily-log pull request of the week.
